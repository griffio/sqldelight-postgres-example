# SqlDelight 2.3.x Postgresql migrations with Flyway 

https://github.com/cashapp/sqldelight

SqlDelight version 2.3.x

```shell
createdb sampledb &&
./gradlew build &&
./gradlew flywayMigrate &&
./gradlew run
```
